# Modular EdTech Examination & Learning Platform

Free-tier-first, modular MCQ exam platform. See docs/PROGRESS.md and docs/DECISIONS.md before starting any work.

## Stack
React + Vite · Supabase (Postgres/Auth/RLS/Storage) · Netlify · Gemini (via backend only)

## Setup
1. `npm install`
2. `cp .env.example .env` and fill in Supabase keys
3. `npm run dev`
